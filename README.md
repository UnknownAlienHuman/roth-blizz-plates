# Roth Blizzard Plates

Roth-style visual skin for Blizzard nameplates and their cast bars on WoW Midnight. It keeps Blizzard nameplate logic and replaces visual regions with Roth textures and fonts.

Screenshot from the [CurseForge gallery](https://www.curseforge.com/wow/addons/roth-blizz-plates).

## Compatibility

- Interface: `120001`, `120005`
- Version: `0.1.14`
- Author: Iurii
- CurseForge reference: [Roth Blizzard Plates](https://www.curseforge.com/wow/addons/roth-blizz-plates)

## Installation

Copy `RothBlizzPlates` into `World of Warcraft/_retail_/Interface/AddOns/`, enable it in the AddOns list, and reload the UI.

## Development status

The current implementation is intentionally visual-only: it does not replace Blizzard nameplate logic and avoids reading unit identity/health values or changing secret anchors. Runtime nameplate and castbar validation is still required for the target Midnight build.
